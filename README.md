# 🌾 Fertilizer Management System

A MERN stack (MongoDB, Express.js, React.js, Node.js) web application designed for fertilizer companies to track availability and requirements of fertilizers across different states and months.
It helps optimize the supply chain by providing real-time insights and management tools.

$ 🚀 Features

# 👤 User Authentication (Login, Logout, Protected Routes)

# 🧮 Dashboard – Shows fertilizer data and insights

@ 🌱 Manage Fertilizers – Add, update, and delete fertilizer details

# 📊 Manage Availability – Track available and required quantities by state/month

# ⚙️ Admin Controls – Authorized users can manage and view data

# 📈 Dynamic Charts and Tables – For better visualization of data

# 🛡️ JWT Token Authorization for secure API access

# 🏗️ Tech Stack

Frontend: React.js, Redux Toolkit, React Router, Tailwind CSS
Backend: Node.js, Express.js, MongoDB, Mongoose
Tools & Libraries: Axios, React Hot Toast, JWT, bcrypt, dotenv
